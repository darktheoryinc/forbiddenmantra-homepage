# Homepage cover permission requests (send one per publisher)

Covers are the publishers' copyrighted artwork. No source I can reach grants us commercial display rights, so each request below asks the publisher in writing. Record the reply in `data/covers.json` through `node scripts/covers.mjs add ... --source-type publisher-permission` once files and permission arrive.

## Request template

> Subject: Permission to display cover images, Forbidden Mantra Press bookstore
>
> We run Forbidden Mantra Press, an independent curated bookstore (forbiddenmantra.com) that recommends books and links each to a retailer. We would like permission to display the front-cover images of the editions listed below on our book pages and homepage shelves, each linking to a retailer page, with the title, author and publisher credited. Please let us know the approved image files or feed, any credit line you require, and the terms. We will not alter the images beyond proportional resizing.

## Harry Potter: edition to settle first

The homepage card is titled "Harry Potter and the Philosopher's Stone" (the UK title) but its first edition in the catalogue is the Scholastic US paperback, ISBN 9780590353427, titled "Sorcerer's Stone". The catalogue also holds the UK Bloomsbury edition, ISBN 9781408855652. A cover may only be used for the edition it belongs to, so decide which edition the card shows: Scholastic (US permissions) or Bloomsbury (UK). The series also carries Warner Bros. / Wizarding World trademarks, so ask the publisher whether character artwork has extra conditions.
