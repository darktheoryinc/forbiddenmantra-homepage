## Where original artwork was and was not found (2026-10-28)
- Git history (78 commits, every branch): the only images are our own site, brand, screenshot and cover files already in the manifest. Branch `main` holds the old one-file homepage, its Velo snippet and a 7.8 KB ZIP of the same two files; the homepage drew placeholder covers in CSS and contains no cover artwork.
- Project folders and the machine: no PSD, EPUB, KPF or cover PDF.
- Wix: the main site's subfolders hold only social-media images; the owner's other Wix sites hold photographs and one Amazon author-page screenshot (Amazon-hosted images, not usable). Google Drive: searched earlier and again this round; no further matches.
- Conclusion: the remaining artwork is not in any location available to this project. It lives where the books were published (the KDP dashboard or the original design files), so it has to come from the owner.

## Can an ebook cover stand in for the other formats?
- The site already shows one cover per work on cards and the book page, chosen from whichever edition has one, and each cover is stored against the single edition it was matched to. Page text now states which edition the cover belongs to ("Cover of the English ebook edition; other editions may use different artwork") so it does not claim to be the paperback or hardcover.
- Nothing we hold proves that paperback, hardcover or audiobook artwork is identical: print covers are separate full-wrap files, and an audiobook cover is square. So no cover has been recorded as belonging to another format. The owner's catalogue showing one cover per record is consistent with shared front artwork but is not proof.
- If the owner confirms that specific titles use identical front artwork in print, those editions can be added to the manifest with that confirmation as evidence. Audiobooks should have their own square files.
